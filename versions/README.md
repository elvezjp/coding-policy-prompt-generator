# versions/

過去リリース時点のスナップショットを保存するディレクトリ。

各リリースごとに `versions/vX.Y.Z/` 配下へ、そのバージョン時点の以下を凍結保存する。

- `src/` — 実装コード（ビルド生成物・キャッシュは除外）
- `spec.md` — 仕様書
- `pyproject.toml` — パッケージメタデータと依存定義
- `uv.lock` — 依存ロックファイル

## 目的

- リリース時点の実装と仕様を後追いで参照できるようにする
- 過去バージョンとの差分比較を容易にする
- `git tag` だけでは追いにくい「当時の全体像」をディレクトリ単位で残す

## 運用ルール

- ここに置かれたファイルは **読み取り専用のアーカイブ**として扱い、後から修正しない
- 新しいリリースを切るタイミングで、現在のルートから対応ファイルをコピーして `versions/v<新バージョン>/` を追加する
